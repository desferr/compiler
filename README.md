## Транслятор-интерпретатор языка программирования
### Описание языка
Синтаксис языка основан на таковом языка программирования Pascal. Язык поддерживает: числовые переменные,   
статические одномерные массивы, арифметические выражения со скобками, присваивание,   
условный оператор, циклы, ввод и вывод.   
#### Лексическая структура языка   
| Элемент | Правило |   
|---|---|   
| Идентификатор | Латинская буква или `_`, затем любое число букв, цифр и `_` |   
| Целая константа | Одна или несколько цифр (`0`, `42`, `123`) |   
| Вещественная константа | Цифры, точка, цифры (`0.5`, `3.14`) |   
| Знак числа | Унарный минус, не входящий в числовую константу |   
| Ключевые слова | `if`, `then`, `else`, `while`, `do`, `begin`, `end`, `read`, `write`, `array` |   
| Знаки операций и разделители | `:=`, `+`, `-`, `*`, `/`, `(`, `)`, `[`, `]`, `,`, `;`, `<`, `>`, `<=`, `>=`, `=`, `<>` |   
| Комментарий | `{ текст комментария }` |   
#### Структура программы   
Программа состоит из необязательных описаний массивов и основного блока `begin ... end`.   
Пример программы, использующей все возможности языка:   
```
array a[100];
begin
  read(n);
  i := 0;
  while i < n do begin { цикл }
    read(a[i]);
    i := i + 1
  end;
  x := 3.14 * (a[0] - 2) / 7.5;
  y = 0;
  if x >= 10 then write(x) else begin write(a[1]); write(n) end;
  if x = 1 then write(0);
  if x <> y then write(y);
  if x <= y then write(y);
  if x > y then write(y)
end
```
#### Операторы   
| Оператор | Запись | Действие |   
|---|---|---|   
| Присваивание | `<имя> := <выражение>`, `<имя>[<выражение>] := <выражение>` | Вычисляет выражение и записывает в переменную или элемент массива |   
| Составной | `begin <оператор>; <оператор>; ... <оператор> end` | Последовательное выполнение, считается одним оператором |   
| Условный | `if <условие> then <оператор>`, `if <условие> then <оператор> else <оператор>` | Если условие истинно - выполняется первая ветвь, иначе вторая (если есть) |   
| Цикл | `while <условие> do <оператор>` | Пока условие истинно, выполняет оператор |   
| Ввод | `read(<имя>)`, `read(<имя>[<выражение>])` | Читает значение со стандартного ввода |   
| Вывод | `write(<выражение>)` | Выводит значение выражения в стандартный вывод |

### Архитектура транслятора-интерпретатора   
Транслятор-интерпретатор состоит из трёх компонентов, работающих последовательно над одной программой:   
| Компонент | Реализация | Вход → выход |   
|---|---|---|   
| Лексический анализатор | Функция-автомат, управляемая таблицей переходов `T[<состояние>][<класс символа>]` | Текст → лексема |   
| Синтаксический анализатор | Магазинный автомат, управляемый таблицей LL(1), генерирующей ОПС | Лексемы → ОПС, таблицы переменных и массивов |   
| Интерпретатор | Выполнение ОПС с магазином операндов | ОПС → результат |

### Лексический анализатор   
Лексический анализатор преобразует текст программы в последовательность лексем:   
пропускает пробелы и комментарии, выделяет идентификаторы, числа, ключевые слова и знаки.   
Реализован как функция `Lexer::next()`: при каждом вызове читает текст с запомненной позиции   
и возвращает очередную лексему.   
Возвращаемая лексема содержит: номер лексемы (`type`), текст (`value`),   
значение целой (`int_value`) или вещественной (`real_value`) константы и   
позицию начала лексемы - строку (`line`) и номер символа в строке (`col`).   
Конец текста возвращается как лексема `EOF` (ограничитель ┴).

#### Семантические программы   
Программы внутри таблицы:   
| № | Действие | Объяснение |   
|---|---|---|   
| 1 | `buffer := <текущий_символ>` | Начало записи идентификатора или числа |   
| 2 | `buffer := buffer + <текущий_символ>` | Продолжение записи идентификатора или числа |   

Завершающие программы (выполняются при Z и Z_STAR, зависят от состояния, из которого вышли):   
| Состояние | Когда вызывается | Действие |   
|---|---|---|   
| ST_S | C_SINGLE, C_EQUAL, C_EOF | C_EOF → лексема L_EOF, иначе тип лексемы определяется по таблице `SINGLE` по символу: `+` → L_PLUS, `-` → L_MINUS, `*` → L_MULTIPLICATION, `/` → L_DIVISION, `(` → L_LEFTPARENTHES, `)` → L_RIGHTPARENTHES, `[` → L_LEFTBRACKET, `]` → L_RIGHTBRACKET, `,` → L_COMMA, `;` → L_SEMICOLON, `=` → L_EQUAL |   
| ST_I | Любой символ, кроме букв и цифр | Слово `buffer` ищется в таблице `KEYWORDS`, если найдено: `if` → L_IF, `then` → L_THEN, `else` → L_ELSE, `while` → L_WHILE, `do` → L_DO, `begin` → L_BEGIN, `end` → L_END, `read` → L_READ, `write` → L_WRITE, `array` → L_ARRAY, иначе L_ID |   
| ST_C | Любой символ, кроме букв, цифр и `.` | Лексема L_INT, значение `int_value` = `buffer` |   
| ST_E | Любой символ, кроме букв, цифр и `.` | Лексема L_REAL, значение `real_value` = `buffer` |   
| ST_A | C_EQUAL | Лексема L_ASSIGN |   
| ST_L | Любой символ | C_EQUAL → L_LESSEREQUAL, C_GREATERTHAN → L_NOTEQUAL, иначе L_LESSERTHAN |   
| ST_M | Любой символ | C_EQUAL → L_GREATEREQUAL, иначе L_GREATERTHAN |

### Грамматика языка   
Терминалы грамматики - вышеописанные лексемы.   
Лексемы `L_ID`, `L_INT` и `L_REAL` записаны своими именами,   
остальные своим текстом (`:=`, `+`, `if` и т.д.).   
Знак `λ` обозначает пустую цепочку.   
Нетерминалы:   
| Нетерминал | Смысл |   
|---|---|   
| P | Программа |   
| R | Описание массивов |   
| M | Продолжение описания массивов |   
| A | Оператор |   
| Q | Продолжение составного оператора |   
| E | Ветка `else` |   
| C | Условие |   
| S | Выражение (сумма/разность) |   
| T | Выражение (умножение/деление) |   
| F | Множитель |   
| G | Операнд под унарным знаком |   
| H | Индекс массива |   
| Z | Пустое место для семантического действия |   
#### Исходная КС-грамматика   
Начальный нетерминал - P.   
```
P → array R P | begin A Q end
R → L_ID [ L_INT ] M
M → , L_ID [ L_INT ] M | ;
A → L_ID H := S Z | if C then A E Z | while C do A Z | begin A Q end | read ( L_ID H ) | write ( S )
Q → ; A Q | λ
E → else A | λ
C → S < S Z | S > S Z | S <= S Z | S >= S Z | S = S Z | S <> S Z
S → S + T | S - T | T
T → T * F | T / F | F
F → ( S ) | + G | - G Z | L_ID H | L_INT | L_REAL
G → ( S ) | L_ID H | L_INT | L_REAL
H → [ S ] | λ
Z → λ
```
#### Преобразование грамматики   
Для LL(1)-анализа грамматику нужно привести к нестрогой нормальной форме Грейбах:   
правая часть каждого правила начинается с терминала, либо пуста.   
Устранение левой рекурсии:   
```
S → S + T | S - T | T    ⇒    S → T U
                               U → + T U | - T U | λ
T → T * F | T / F | F    ⇒    T → F V
                               V → * F V | / F V | λ
```
Для устранения левой рекурсии были добавлены нетерминалы:   
| Нетерминал | Смысл |   
|---|---|   
| U | Продолжение выражения (сумма/разность) |   
| V | Продолжение выражения (умножение/деление) |   

Факторизация:   
```
C → S D
D → < S Z | > S Z | <= S Z | >= S Z | = S Z | <> S Z
```
Для факторизации был добавлен нетерминал D, обозначающий операцию сравнения и правый операнд.   
Приведение к нормальной форме Грейбах:   
```
T → F V ⇒ T → ( S ) V | + G V | - G V | L_ID H V | L_INT V | L_REAL V
S → T U ⇒ S → ( S ) V U | + G V U | - G V U | L_ID H V U | L_INT V U | L_REAL V U
C → S D ⇒ C → ( S ) V U D | + G V U D | - G V U D | L_ID H V U D | L_INT V U D | L_REAL V U D
```
#### Грамматика в нестрогой нормальной форме Грейбах   
```
P → array R P | begin A Q end
R → L_ID [ L_INT ] M
M → , L_ID [ L_INT ] M | ;
A → L_ID H := S Z | if C then A E Z | while C do A Z | begin A Q end | read ( L_ID H ) | write ( S )
Q → ; A Q | λ
E → else A | λ
C → ( S ) V U D | L_ID H V U D | L_INT V U D | L_REAL V U D | + G V U D | - G V U D
D → < S Z | > S Z | <= S Z | >= S Z | = S Z | <> S Z
S → ( S ) V U | L_ID H V U | L_INT V U | L_REAL V U | + G V U | - G V U
U → + T U | - T U | λ
T → ( S ) V | L_ID H V | L_INT V | L_REAL V | + G V | - G V
V → * F V | / F V | λ
F → ( S ) | L_ID H | L_INT | L_REAL | + G | - G Z
G → ( S ) | L_ID H | L_INT | L_REAL
H → [ S ] | λ
Z → λ
```

### Генерация ОПС   
ОПС - последовательность элементов, пронумерованных с нуля.   
Каждый элемент имеет тип:   
| Тип | Что хранит |   
|---|---|   
| Переменная | Номер в таблице переменных |   
| Массив | Номер в таблице массивов |   
| Константа | Число (целое или вещественное) |   
| Метка | Номер элемента ОПС, на который передаётся управление |   
| Операция | Код одной из операций |   

Во время трансляции ведутся две таблицы имён: таблица переменных и таблица массивов.   
#### Список операций ОПС   
| Операция | Операнды | Результат |   
|---|---|---|   
| `+`, `-`, `*`, `/` | 2 значения | Число |   
| `-'` | 1 значение | Число |   
| `<`, `>`, `<=`, `>=`, `=`, `<>` | 2 значения | Логическое значение |   
| `i` | Ссылка на массив, индекс | Ссылка на элемент массива |   
| `:=` | Ссылка, значение | - (записывает значение по ссылке) |   
| `r` | Ссылка | - (читает значение и записывает по ссылке) |   
| `w` | Значение | - (Выводит значение) |   
| `j` | Метка | - (безусловный переход) |   
| `jf` | Значение условия, метка | - (переход, если условие ложно) |   
| `m1` | Ссылка на массив, количество элементов | - (Выделяет память, записывает в паспорт массива её начало и размер) |   
#### Обозначение семантических действий   
| Обозначение | Действие |   
|---|---|   
| □ | Пустое |   
| `a` | Записать в ОПС операнд-ссылку на массив или на переменную. Имя берётся из текущей лексемы L_ID |   
| `k` | Записать в ОПС константу из текущей лексемы L_INT или L_REAL |   
| `+`, `-`, `*`, `/`, `<`, `>`, `<=`, `>=`, `=`, `<>`, `:=`, `i`, `r`, `w`, `m1` | Записать в ОПС соответствующую операцию |   
| `-'` | Записать операцию унарного минуса |   
| 1 ... 7 | Семантические программы |   
#### Семантические программы   
| № | Место применения | Действие |   
|---|---|---|   
| 1 | После условия в `if` и `while` | Положить `k` в магазин меток, записать в ОПС пустой элемент, затем операцию `jf` |   
| 2 | `else` | Заполнить метку на вершине магазина значением `k + 2` и снять её, положить `k` в магазин, записать пустой элемент и операцию `j` |   
| 3 | Конец `if` | Заполнить метку на вершине магазина значением `k`, снять её |   
| 4 | Начало `while` | Положить `k` в магазин меток (адрес начала цикла) |   
| 5 | Конец `while` | Заполнить метку на вершине значением `k + 2` и снять её, записать в ОПС метку, равную снятому со следующей вершины адресу начала цикла, и операцию `j` |   
| 6 | L_ID в описании массива | Если имя уже есть в таблице массивов - ошибка, иначе занести имя в таблицу и записать в ОПС ссылку на массив |   
| 7 | `[` в индексе | Проверить, что последний записанный в ОПС операнд - массив, иначе ошибка |
